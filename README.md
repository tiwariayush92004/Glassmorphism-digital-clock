# Glassmorphism Digital Clock 🕒✨

A modern, responsive, and minimalist web-based digital clock built with clean HTML, CSS, and vanilla JavaScript. Features a dark-mode aesthetic with a glassmorphism card effect, subtle neon glow, and an ambient grid background.

---

## 🌟 Features

* **Real-time Clock:** Displays local time updating seamlessly every second.
* **Zero Initial Lag:** Instant time display upon load without the typical 1-second `setInterval` delay.
* **Modern UI:** Built with CSS custom properties, backdrop blur filters, and glow effects.
* **Responsive Layout:** Centered flexbox structure that adapts to any screen size.
* **Lightweight & Fast:** Pure vanilla code with zero external dependencies or heavy libraries.
